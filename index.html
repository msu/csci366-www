IntelliJ Plugin

The x366 plugin adds syntax highlighting, debugging, and C-- support. It needs IntelliJ 2026.2 or newer.

Installation instructions
  1. Open Settings and select Plugins
  2. Click the gear icon and select Manage Plugin Repositories...
  3. Click +, then add https://msu.github.io/csci366-www/plugin/updatePlugins.xml
  4. Click OK
  5. In the Marketplace tab, search for x366 and click Install
  6. Restart IntelliJ if it asks

To install by hand, download the plugin zip, then select Install Plugin from Disk... from the gear icon.
